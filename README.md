## Running the Notebooks

1. Open in Google Colab (colab.research.google.com)
2. Upload all CSV files to the Colab /content/ directory
3. For Tasks 4–5: replace MONGO_URI with your MongoDB Atlas connection string
4. Run all cells sequentially
